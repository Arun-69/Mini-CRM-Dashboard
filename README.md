# Mini-CRM-Dashboard

Mini CRM Dashboard

A simple CRM application built using the MERN Stack.

Tech Stack
React.js
Node.js
Express.js
MongoDB
Material UI
JWT Authentication
Features
User Login & Registration
Forgot & Reset Password
Lead Management
Company Management
Task Management
Dashboard
User Assignment
Backend Setup
npm install
npm start


Create .env file:

PORT=5000
MONGODB_URI=your_mongodb_url
JWT_SECRET=your_secret_key
FRONTEND_URL=your_frontend_url

Frontend Setup
npm install
npm run dev


Create .env file:

VITE_API_URL=your_backend_api_url

API Documentation


Deployment
Frontend: Vercel
Backend: Render
Database: MongoDB Atlas
